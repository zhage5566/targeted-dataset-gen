# 中国用户使用说明 · v2.2

本工具在本机运行。Windows 完整包无需安装 Python、无需 GPU、无需 API Key；生成和整理过程中不上传用户语料。中文界面是默认设置。公开行业语料作为独立包提供，下载后可以离线处理。

## 下载安装

1. 国内优先打开 [ModelScope 文件页](https://www.modelscope.cn/datasets/zhouyang55666/customer_json/files)。在 `tools/` 下载 `TargetedDatasetGen-v2.2.0-Windows.zip`。
2. 解压到可写目录，例如桌面。双击 `TargetedDatasetGen.exe` 或 `启动程序.bat`。
3. 需要公开语料时，在 `corpora/` 下载 `IndustryCorpora-v2.2.0.zip` 并解压。语料包与程序包分开，避免每次升级重复下载数据。
4. 文件名和目录支持中文、空格；输出采用 UTF-8。CSV 输入支持 UTF-8 BOM，Excel 保存时选“CSV UTF-8”。

也可使用 [GitHub Release](https://github.com/zhage5566/targeted-dataset-gen/releases/tag/v2.2.0)。程序运行不依赖 GitHub 或 Hugging Face 连通性。不包含第三方模型，也没有模型 API 费用。

## 三分钟生成中文物流语料

1. 在“行业与训练方向”只勾选电商，清空业务选择后选“查询物流”。
2. 只勾“意图识别 + 槽位抽取”。顶部“语料语言”选 `zh`，“标签值语言”选 `follow` 或 `zh`。
3. 在“输入模板”启用模板，加载 `examples/logistics-templates.json`。可移动 `${占位词}`，修改对应变量词库。
4. 在“输入输出关联”加载 `examples/association-rules.json`，多个输入词可指向同一个意图名称。
5. 在“自定义数据格式”选 `custom`，加载 `examples/format-logistics.json`，按需修改输出 key。
6. 在“输出与质量设置”先用 1 MiB 测试，指定输出路径，点击“开始生成”。阅读相邻 `.quality.json` 质量报告，再扩大规模。

英文界面与英文语料可分别选择；英文模式使用原生英文模板。中文公开语料不会被自动翻译，原始实体和标签不会被静默改写。

## 整理公开行业语料

打开新增“行业语料工作台”。目录中 `collected` 表示独立语料包已收集，`reference_only` 表示官方参考入口，不能理解为已下载或已获再分发许可。

| 语料 | 选择原始目录 | 适配器 | 可选兼容导出 |
|---|---|---|---|
| 中文 CrossWOZ | `IndustryCorpora-v2.2.0/raw/crosswoz` | `crosswoz` | `messages`，保留多轮上下文 |
| 英文 BANKING77 | `IndustryCorpora-v2.2.0/raw/banking77` | `banking77` | `messages` / `rasa` |
| 英文 CLINC150 | `IndustryCorpora-v2.2.0/raw/clinc150` | `clinc150` | `messages` / `rasa` |
| 自己的 JSONL / JSON / CSV | 选择文件 | `generic` | 依据标注类型选择 |

填写一个**不存在的新输出目录**，设置每标签训练种子上限，点击“整理、隔离并导出”。文件较大时需等待，进程在后台处理，主界面仍可响应。已存在的结果不会被自动覆盖。

通用输入单文件限制 256 MiB、单批最多 20 万条。CrossWOZ 专用适配器允许 ZIP 内单个 JSON 至多 512 MiB；完整训练集解析建议预留约 2 GB 可用内存。低内存机器可以直接使用语料包中已整理的文件。

默认 `random` 是按标签设置配额、固定随机种子的均衡选取。实验选项 `coverage` 优先不同词面结构，再贪心覆盖训练样本中的低频字符三元组；它不理解语义，也不保证比随机选取更有效。首次基线实验中该选项效果更差，详见[实验说明](research-and-integration.md)。

输出内容：

- `train.jsonl`、`validation.jsonl`、`test.jsonl`：质量筛选后的三份数据，保留原始划分归属。筛选可能减少原始数量。
- `selected-train.jsonl`：只从清理后的训练侧选取的均衡种子。
- `quarantine.jsonl`：隔离的重复、标签冲突、训练评测重叠或缺少槽位文本证据的记录及原因。
- `report.json`：数量、标签覆盖、隔离原因、配置和源文件 SHA-256。
- 选择 `messages` 或 `rasa` 时，会额外输出三份对应格式文件。Rasa 导出为 `.rasa.yml`，使用兼容 YAML 的 JSON 语法，支持单轮意图与唯一、非重叠实体跨度。

源文件及原始划分在语料包 `raw/` 中完整保留。处理结果在 `prepared/`；不能把经过筛选的测试集成绩直接冒充原始官方基准成绩。

## 导入自己的任意行业标签

通用格式示例（同一客户会话或同一条原始种子的扩增应使用相同 `group_id`）：

```json
{"input":"我要查询包裹进度","output":"查询物流","split":"train","group_id":"conversation-001","language":"zh","industry":"电商"}
```

`output` 可为字符串标签、JSON 对象或已标注的答案；不会从无标签文本猜答案。字段名不同可在工作台填写“输入字段”和“答案字段”。工作台字段映射支持顶层字段；旧“语料种子导入”仍支持点路径映射。

`split` 支持 `train`、`validation`、`test`（兼容 `val/dev`）。没有划分时，按明确 `group_id` 或归一化完整输入的稳定哈希分配约 80%/20%；比例是期望值，小数据不保证刚好 80/20。所有同组数据一起划分。

多轮输入使用 `history` 消息数组。判重和答案冲突检测使用“历史 + 当前输入”，避免把不同上下文中的“好的”误判为标签冲突。已有完整上下文仍不代表解决了语义近重复。

工作台支持任意行业和原始标签的**整理、选取及兼容导出**。原有合成生成器仍支持五行业、68 场景、七任务；将工作台结果导入原生成器时，必须先人工确认语义并提供其支持的 `scene/task` 和答案格式。不要把 BANKING77 的 77 类自动压成内置的 12 个金融场景。CrossWOZ 多标签行为也不能无损地强转为单标签意图。

## 测试集如何使用

先固定原始 train/validation/test，再只用训练种子做扩增。工作台保留原始划分，发现训练记录与评测输入完全相同时，隔离训练侧整个来源组；不同答案的相同完整输入全部进入隔离区供复核。

原生成器“测试种子扩增”用于构建鲁棒性测试变体，应与真实独立测试集分开汇报。不得先扩增后逐行随机切分。字符判重、来源隔离都不保证拦住所有语义改写或跨语言泄漏。

## 源码与命令行

Python 3.10+，运行时仅用标准库。源码包不需要安装网络依赖：

```powershell
python app.py
python -m corpus_workbench --source "D:\语料\raw\banking77" --out "D:\语料\新整理结果" --adapter banking77 --per-label 100 --strategy random --export-format rasa
python -m corpus_workbench --source "自己的语料.csv" --out "新的整理目录" --input-field question --output-field label
python -m corpus_benchmark "D:\语料\prepared\banking77" --per-label 20 --out "新的对照报告.json"
python -m unittest discover -s tests -v
```

仅在自行构建 EXE 时需要安装 `requirements-build.txt` 后运行 `python build.py`；普通用户直接使用发布包。wheel 安装后可运行 `targeted-dataset-ui` 和 `targeted-corpus`。

## 常见问题

- **为什么整理后少了数据？** 检查 `quarantine.jsonl` 和报告。原始文件还在，不静默删除源记录。
- **为什么英文语料仍是英文？** 界面切换不翻译数据。中英文生成使用相应语言模板；公开语料保留原文。
- **为什么不能直接扩增医疗等新标签？** 工作台可处理该标签体系，但合成模板与业务约束需要另行设计；当前不自动推断医疗标注或回答。
- **Rasa 导出失败？** 检查是否多轮、包含标注控制字符、槽位出现多次或实体重叠。可以改选保留信息更完整的 `messages`。
- **如何复现？** 保留输入 SHA、版本、参数、随机种子和划分；生成器另外固定参考日期并关闭跨批次历史去重，或使用相同历史快照。
- **能无限扩增吗？** 组合按需生成，可扩展词池，但受内存、磁盘和有效组合约束；数量不等于质量。
