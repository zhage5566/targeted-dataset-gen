# 方法贡献、成熟项目融合与可复现实验

本项目定位为离线数据工程工具与研究实验底座，不宣称首创模板扩增、去重或贪心覆盖算法。

## v2.2 实际实现的组合方法

1. **上下文感知的来源隔离**：输入键包含角色和完整历史。保留官方划分，训练侧出现与评测相同输入时隔离整个来源组，避免只删泄漏的一行而留下其相关扩增。冲突答案双向隔离，不任意挑一个标签。
2. **先约束、再选取**：槽位必须有文本证据；完成来源隔离、重复与标签冲突筛选后，才执行每标签预算选取。生成器继续执行原有场景与业务流程约束。
3. **训练侧词面覆盖实验选取器**：先偏好未见结构，再按新增字符三元组的训练逆文档频率得分贪心选取；长度采用平方根归一化。所有频率仅来自该类训练池，不接触测试标签。固定种子打乱候选，控制平分时顺序。
4. **数据来源可审计**：保留上游提交、原始文件、SHA-256、归一化转换规则、隔离原因和选取参数。原始数据、整理数据与合成示例分别记录。

这是工程方法组合与算法实验实现。是否具有论文级新颖性，需要更完整的相关工作比较；是否有效，需要跨数据集、跨模型实验，不能用生成速度、随机性或单元测试替代。

## 融合了哪些优秀项目

| [ConvLab-2 / CrossWOZ](https://github.com/thu-coai/ConvLab-2) | 原生语料适配器，保留用户行为标签、会话上下文和官方划分 | 使用原作者数据并保留许可；未集成其训练模型 |

## 首次对照实验：保留失败结果

数据：BANKING77，先经本项目固定规则清理，训练 9,992 条、测试 3,079 条。测试集经过筛选，因此不是未经处理的官方榜单分数。

模型：标准库实现的字符 2/3-gram 多项式朴素贝叶斯，加一平滑。每标签 20 条，共 1,540 条训练样本；种子 11、42、73。超参数相同，无大模型 API、无 GPU。比较按标签随机选取与词面覆盖选取，均不使用测试数据参与选取。

| 选取策略 | 三种子平均 Accuracy | 三种子平均 Macro-F1 |
|---|---:|---:|
| 均衡随机 random | 0.71755 | 0.72207 |
| 词面覆盖 coverage | 0.60052 | 0.60485 |

**本次 coverage 明显更差，故默认使用 random。** 词面稀有特征可能偏离代表性表达；这是一个待验证解释，不是已经证实的因果结论。覆盖选取作为研究开关保留，不宣传效果提升。逐次结果和源文件哈希见 `validation/v22-banking77-coverage-benchmark.json`。

复现：下载语料包，对 `raw/banking77` 运行工作台整理，再运行：

```powershell
python -m corpus_benchmark "整理后的banking77目录" --per-label 20 --out "新的实验报告.json"
```
